📧 Notifications par Email (EmailJS)

Comment configurer EmailJS :

1. Créez un compte gratuit sur emailjs.com
2. Ajoutez un service email (Gmail, Outlook...)
3. Créez un template email avec ces variables :
{{order_id}} {{customer_name}} {{phone}} {{city}} {{address}} {{product}} {{quantity}} {{product_price}} {{delivery_price}} {{total}} {{date}}

4. Copiez votre Public Key, Service ID et Template ID ci-dessous

🔒 Changer le Mot de Passe Admin

Mot de passe par défaut : admin123 — changez-le immédiatement !

🚀 Déploiement sur GitHub Pages

Étapes pour mettre en ligne :

1. Créez un compte sur github.com
2. Cliquez sur New repository → nommez-le (ex: ma-boutique)
3. Uploadez le fichier index.html dans le dépôt
4. Allez dans Settings → Pages → Source : main branch
5. Votre boutique sera accessible sur votre-username.github.io/ma-boutique

⚠ Important : Les produits, villes et commandes sont sauvegardés dans ce navigateur. Configurez EmailJS pour recevoir les commandes par email. Exportez régulièrement le CSV.
